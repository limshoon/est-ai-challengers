# Day 4. 함수와 객체지향 프로그래밍

> 작성일: 2026-07-16

## 📝 오늘 배운 내용 요약
1. **함수(Function)의 개념과 활용**
  - 함수의 정의와 호출 방법을 학습했다.
  - 매개변수(parameter)와 반환값(return value)의 개념을 이해하고 다양한 형태의 함수를 작성해보았다.
  - 코드의 중복을 줄이고 재사용성을 높이기 위해 함수를 사용하는 이유를 이해했다.
2. **Lambda 함수와 map/filter**
  - `lambda`를 이용해 간단한 익명 함수를 작성하는 방법을 학습했다.
  - `map()`을 활용하여 리스트의 모든 요소를 일괄적으로 변환하는 방법을 실습했다.
  - `filter()`를 사용하여 조건에 맞는 데이터만 추출하는 방법을 익혔다.
  - 함수형 프로그래밍의 기본적인 개념을 경험할 수 있었다.
3. **내장 함수와 표준 모듈**
  - Python에서 기본 제공하는 다양한 내장 함수(`len()`, `sum()`, `max()`, `min()`, `sorted()` 등)의 활용법을 익혔다.
  - `math`, `random`, `datetime` 등 자주 사용하는 표준 모듈을 불러와 사용하는 방법을 학습했다.
  - `import` 문을 이용하여 필요한 모듈을 프로젝트에서 활용하는 방법을 이해했다.
4. 함수 심화
  - `args`와 `*kwargs`를 이용하여 가변 인자를 처리하는 방법을 학습했다.
  - 재귀함수(Recursive Function)의 개념과 자기 자신을 호출하는 구조를 이해했다.
  - 데코레이터(Decorator)를 통해 기존 함수의 기능을 수정하지 않고 새로운 기능을 추가하는 방법을 학습했다.
5. **예외처리(Exception Handling)**
  - 프로그램 실행 중 발생하는 오류를 처리하기 위해 `try`, `except`, `else`, `finally` 문을 사용하는 방법을 익혔다.
  - 예외처리를 통해 프로그램이 오류로 종료되지 않고 안정적으로 실행될 수 있음을 이해했다.
6. **파일 입출력(File I/O)**
  - 파일을 생성하고 읽고 쓰는 방법을 실습했다.
  - `open()` 함수와 `with` 문을 활용하여 파일을 안전하게 관리하는 방법을 익혔다.
  - 텍스트 파일의 저장 및 읽기 과정을 이해했다.
7. **객체지향 프로그래밍(OOP)**
  - 클래스(Class)와 객체(Object)의 개념을 이해했다.
  - 생성자(`__init__`)와 인스턴스 변수의 역할을 학습했다.
  - 객체를 생성하여 속성과 메서드를 사용하는 방법을 실습했다.
8. **객체지향 심화**
  - 상속(Inheritance)을 통해 기존 클래스를 재사용하는 방법을 학습했다.
  - 다형성(Polymorphism)을 이용하여 동일한 인터페이스로 다양한 객체를 사용할 수 있음을 이해했다.
  - 클래스 메서드(Class Method)의 개념과 `@classmethod`의 활용법을 익혔다.
## 💭 오늘의 회고
1. **배운 점**
  - Python에서 함수를 활용하면 코드의 재사용성과 유지보수성이 크게 향상된다는 점을 이해했다.
  - Lambda 함수와 `map`, `filter`를 사용하면 반복문을 더욱 간결하게 작성할 수 있다는 점을 알게 되었다.
  - 예외처리를 통해 예상하지 못한 오류에도 프로그램이 안정적으로 동작하도록 만들 수 있다는 점이 인상적이었다.
  - 객체지향 프로그래밍은 현실 세계의 객체를 코드로 표현하는 방식이며, 앞으로 규모가 큰 프로젝트에서 매우 중요한 개념이라는 것을 이해했다.
2. **어려운 점/개선할 점**
  - `args`, `*kwargs`와 데코레이터는 문법이 다소 복잡하여 한 번에 이해하기 어려웠다.
  - 재귀함수의 호출 과정과 종료 조건을 머릿속으로 추적하는 것이 쉽지 않았다.
  - 상속과 다형성은 개념은 이해했지만 실제 프로젝트에서 언제 사용하는지에 대한 경험이 부족했다.
3. **액션 플랜**
  - 함수와 객체지향 문제를 직접 작성하며 복습한다.
  - `lambda`, `map`, `filter`를 활용한 간단한 문제를 추가로 풀어본다.
  - 예외처리와 파일 입출력을 활용한 미니 프로젝트를 제작해본다.
  - 클래스와 상속을 활용하여 간단한 프로그램을 구현하며 객체지향 개념을 익힌다.
