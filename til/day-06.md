# Day 6. EDA와 기술통계분석

> 작성일: 2026-07-21

## **📝 오늘 배운 내용 요약**
1. **EDA의 기본 개념과 데이터 구조 확인 방법을 학습했다**
  - EDA는 Exploratory Data Analysis의 약자로, 본격적인 분석 전에 데이터의 구조와 특징을 탐색하는 과정이다.
  - `head()`, `tail()`, `sample()`을 활용해 데이터의 일부를 빠르게 확인했다.
  - `shape`를 통해 데이터의 행과 열 개수를 확인하고, `dtypes`와 `info()`를 통해 각 컬럼의 자료형과 결측치 여부를 파악했다.
  - `describe()`를 사용해 수치형 데이터의 평균, 표준편차, 최솟값, 최댓값, 사분위수 등의 기술통계량을 확인했다.
  - 문자열 컬럼까지 포함해 확인할 때는 `describe(include="all")`을 사용해야 한다는 점을 배웠다.
2. **결측치와 범주형 데이터의 분포를 확인했다**
  - `isnull()`과 `isna()`를 사용해 데이터의 결측치 여부를 확인했다.
  - `df.isnull().sum()`을 사용하면 컬럼별 결측치 개수를 효율적으로 확인할 수 있었다.
  - `unique()`를 사용해 컬럼에 포함된 고유값 목록을 확인했다.
  - `nunique()`를 통해 고유값의 개수를 구하고, `value_counts()`를 통해 각 값의 등장 횟수와 비율을 확인했다.
  - `unique()`, `nunique()`, `value_counts()`는 비슷해 보이지만 각각 반환하는 정보와 자료형이 다르다는 점을 이해했다.
3. **데이터를 정렬하고 순위를 계산하는 방법을 학습했다**
  - `sort_values()`를 사용해 특정 컬럼의 값을 기준으로 데이터를 오름차순 또는 내림차순으로 정렬했다.
  - 여러 컬럼을 기준으로 정렬할 때 컬럼명과 `ascending` 값을 리스트로 전달할 수 있었다.
  - `nlargest()`와 `nsmallest()`를 활용해 특정 컬럼을 기준으로 상위 또는 하위 데이터를 간단하게 추출했다.
  - `rank()`를 사용해 원본 데이터의 순서를 유지하면서 순위 컬럼을 추가했다.
  - `idxmax()`와 `idxmin()`을 활용해 최댓값이나 최솟값이 위치한 행의 인덱스를 찾았다.
  - `loc[]`와 결합하면 최댓값이나 최솟값을 가진 행의 전체 정보를 가져올 수 있었다.
4. **인덱싱과 조건 필터링을 학습했다**
  - 대괄호를 사용해 하나 또는 여러 개의 컬럼을 선택했다.
  - `loc[]`는 인덱스와 컬럼의 라벨을 기준으로 데이터를 선택한다는 점을 배웠다.
  - `iloc[]`는 행과 열의 정수 위치를 기준으로 데이터를 선택한다는 점을 배웠다.
  - `loc[]`의 범위 선택은 끝값을 포함하지만, `iloc[]`의 범위 선택은 일반적인 파이썬 슬라이싱처럼 끝값을 포함하지 않는다는 차이를 확인했다.
  - 비교 연산자를 사용해 특정 조건을 만족하는 데이터만 필터링했다.
  - 다중 조건에서는 `&`, `|`, `~` 연산자를 사용하고, 각 조건을 반드시 괄호로 묶어야 한다는 점을 배웠다.
  - `query()`를 사용하면 복잡한 조건을 문자열 형태로 비교적 읽기 쉽게 작성할 수 있었다.
  - `at[]`과 `iat[]`을 사용해 특정 위치의 단일 값에 빠르게 접근했다.
  - `set_index()`와 `reset_index()`를 통해 인덱스를 설정하거나 초기화했다.
5. **그룹별 집계와 데이터 변환 방법을 학습했다**
  - `groupby()`를 사용해 부서나 직무와 같은 기준으로 데이터를 그룹화했다.
  - 그룹별 평균, 합계, 개수, 최댓값, 최솟값 등의 통계량을 계산했다.
  - `agg()`를 사용해 하나의 컬럼에 여러 통계 함수를 적용하거나, 여러 컬럼에 서로 다른 통계 함수를 적용했다.
  - Named Aggregation을 활용하면 집계 결과의 컬럼명을 직접 지정할 수 있었다.
  - `transform()`은 그룹별 계산 결과를 원본 데이터의 행 개수와 동일한 형태로 반환한다는 점을 배웠다.
  - 이를 활용해 각 직원의 급여와 부서 평균 급여를 비교하는 새로운 컬럼을 만들 수 있었다.
  - `filter()`를 사용해 특정 조건을 만족하는 그룹 전체만 추출했다.
6. **피벗 테이블과 교차표를 활용한 분석 방법을 학습했다**
  - `pd.crosstab()`을 사용해 두 범주형 변수의 조합별 빈도수를 확인했다.
  - `normalize` 옵션을 사용해 빈도수가 아닌 비율 형태의 교차표를 만들었다.
  - `pivot_table()`을 활용해 행과 열의 기준을 설정하고, 그룹별 평균이나 합계 등의 통계를 표 형태로 정리했다.
  - `groupby()`와 `pivot_table()`은 모두 그룹별 집계가 가능하지만, `groupby()`는 결과를 세로 형태로 확인하기 좋고 `pivot_table()`은 행과 열로 재구성된 표를 만들 때 유용하다는 차이를 배웠다.
  - `cut()`을 사용해 수치 데이터를 직접 지정한 구간으로 나누고, `qcut()`을 사용해 각 구간의 데이터 개수가 비슷하도록 나누는 방법을 학습했다.
## **💭 오늘의 회고**
1. **배운 점**
  - 데이터를 분석하기 전에 데이터의 크기, 자료형, 결측치, 고유값과 같은 기본 구조를 먼저 확인하는 과정이 중요하다는 점을 배웠다.
  - Pandas의 다양한 함수가 각각 독립적으로 사용되기보다 서로 조합될 때 더욱 효과적이라는 점을 알게 됐다.
  - 특히 `groupby()`, `agg()`, `transform()`, `pivot_table()`을 활용하면 복잡한 데이터도 기준별로 쉽게 요약하고 비교할 수 있었다.
2. **어려운 점/개선할 점**
  - `loc[]`와 `iloc[]`의 차이, 특히 슬라이싱에서 마지막 값의 포함 여부가 헷갈렸다.
  - 다중 조건 필터링에서 `and`, `or`가 아닌 `&`, `|`를 사용하고 각 조건을 괄호로 묶어야 한다는 점에 주의해야 했다.
  - `groupby()` 이후 생성되는 결과의 인덱스 구조와 `reset_index()`가 필요한 상황을 구분하는 것이 어려웠다.
  - `agg()`, `transform()`, `filter()`는 모두 그룹 데이터를 다루지만 반환되는 결과의 형태가 달라 추가적인 연습이 필요하다고 느꼈다.
3. **액션 플랜**
  - 새로운 데이터셋을 불러온 후 `head()`, `info()`, `describe()`, `isnull().sum()`을 순서대로 실행하는 EDA 과정을 반복 연습할 예정이다.
  - `loc[]`, `iloc[]`, 불리언 인덱싱을 활용해 동일한 데이터를 여러 방식으로 선택해볼 예정이다.
  - `groupby()`와 `pivot_table()`로 동일한 분석 결과를 각각 구현하고 결과의 형태를 비교할 예정이다.
  - 결측치가 포함된 실제 데이터셋을 활용해 그룹별 통계와 조건 필터링을 직접 수행해볼 예정이다.
4. **함께 나누고 싶은 점**
  - EDA는 단순히 데이터를 출력해보는 과정이 아니라, 이후 분석 방향을 결정하고 데이터의 문제점을 발견하는 중요한 단계이다.
  - `info()`와 `isnull().sum()`만 사용해도 데이터의 자료형 오류나 결측치 문제를 빠르게 발견할 수 있다.
  - 그룹별 분석에서는 원하는 결과가 원본 행과 같은 길이인지, 그룹별로 축약된 결과인지에 따라 `transform()`과 `agg()`를 구분해 사용하는 것이 중요하다.
