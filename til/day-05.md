# Day 5. 데이터 분석 기초

> 작성일: 2026-07-20

## **📝 오늘 배운 내용 요약**
1. **NumPy 배열의 기본 구조와 활용 방법**
  - NumPy는 파이썬에서 대량의 수치 데이터를 빠르게 계산하기 위한 라이브러리이다.
  - `np.array()`를 사용하여 1차원 및 2차원 배열을 생성하는 방법을 배웠다.
  - `shape`, `ndim`, `dtype`, `size`를 활용하여 배열의 형태, 차원, 자료형, 원소 개수를 확인했다.
  - NumPy 배열은 하나의 배열 안에서 동일한 자료형을 사용한다는 특징이 있다.
  - 배열의 인덱싱과 슬라이싱을 통해 필요한 값이나 범위를 선택했다.
  - 2차원 배열에서는 `배열[행, 열]` 형식으로 원하는 위치의 값을 조회했다.
2. **NumPy 배열 연산과 데이터 필터링**
  - 배열 전체에 덧셈, 곱셈 등의 연산을 적용하는 벡터 연산을 배웠다.
  - 반복문을 사용하지 않고 가격 할인, 환율 변환, 온도 변환, 매출 계산 등을 수행했다.
  - 크기가 다른 값이나 배열을 자동으로 맞춰 계산하는 브로드캐스팅 개념을 이해했다.
  - `mean()`, `sum()`, `max()`, `min()`, `std()`를 사용하여 기본 통계값을 계산했다.
  - `argmax()`와 `argmin()`을 활용하여 최댓값과 최솟값이 위치한 인덱스를 찾았다.
  - 비교 연산으로 불리언 배열을 만들고, 조건을 만족하는 데이터만 선택했다.
  - `np.where()`를 사용하여 조건에 따라 값을 분류하거나 조건을 만족하는 위치를 확인했다.
  - `np.sort()`와 `reshape()`를 사용하여 배열을 정렬하고 형태를 변경했다.
3. **Pandas의 Series와 DataFrame**
  - Pandas는 표 형태의 데이터를 다루기 위한 데이터 분석 라이브러리라는 것을 배웠다.
  - Series는 인덱스와 값으로 구성된 1차원 데이터이고, DataFrame은 여러 Series가 모인 2차원 표라는 것을 이해했다.
  - 딕셔너리, 리스트, 딕셔너리의 리스트를 활용하여 DataFrame을 생성했다.
  - `df["컬럼명"]`은 Series를 반환하고, `df[["컬럼명"]]`은 DataFrame을 반환한다는 차이를 배웠다.
  - `loc`와 `iloc`를 사용하여 이름이나 위치를 기준으로 행을 선택했다.
  - 불리언 인덱싱을 활용하여 특정 조건을 만족하는 행만 필터링했다.
4. **DataFrame의 계산, 통계 및 정렬**
  - 기존 컬럼을 이용한 계산식을 작성하여 새로운 컬럼을 추가했다.
  - 가격과 주문 수량을 곱하여 총매출액을 계산하거나, 과목 점수를 이용해 총점과 평균을 계산했다.
  - `drop()`을 사용하여 필요하지 않은 컬럼을 삭제했다.
  - `mean()`, `sum()`, `max()`, `min()` 등의 통계 메서드를 DataFrame에 적용했다.
  - `idxmax()`와 `idxmin()`을 사용하여 가장 큰 값이나 작은 값을 가진 항목의 이름을 찾았다.
  - `sort_values()`를 활용하여 특정 컬럼을 기준으로 데이터를 오름차순 또는 내림차순으로 정렬했다.
  - NumPy와 Pandas를 함께 사용하여 주식 포트폴리오의 평가금액, 수익금, 수익률 등을 분석했다.
## **💭 오늘의 회고**
1. **배운 점**
  - 파이썬의 일반 리스트보다 NumPy 배열을 사용하면 반복문 없이 여러 데이터를 한 번에 계산할 수 있다는 점을 배웠다.
  - 데이터 분석에서는 단순히 최댓값을 찾는 것뿐만 아니라, 해당 값이 어떤 위치나 항목에 있는지를 확인하는 것도 중요하다는 것을 알게 되었다.
  - Pandas DataFrame을 활용하면 엑셀과 비슷한 표 구조의 데이터를 코드로 생성하고 수정할 수 있었다.
  - NumPy에서 배운 배열 연산과 불리언 인덱싱이 Pandas에서도 동일하게 활용된다는 점을 이해했다.
  - 새로운 컬럼 생성, 조건 필터링, 통계 계산, 정렬의 과정을 조합하면 기본적인 데이터 분석을 수행할 수 있다는 것을 배웠다.
2. **어려운 점/개선할 점**
  - 2차원 배열에서 `axis=0`과 `axis=1`이 각각 어떤 방향을 의미하는지 구분하는 것이 어려웠다.
  - NumPy 배열과 파이썬 리스트에서 `+`와  연산의 결과가 다르기 때문에 혼동하지 않도록 주의해야 했다.
  - `df["컬럼"]`과 `df[["컬럼"]]`의 반환 자료형이 서로 다르다는 점이 헷갈렸다.
  - 컬럼을 삭제할 때 `drop()`의 `axis=1` 옵션을 지정해야 한다는 점을 기억할 필요가 있다.
  - 불리언 인덱싱에서 여러 조건을 사용할 때 각각의 조건을 괄호로 묶고 `&` 또는 `|`를 사용해야 한다는 점을 추가로 연습해야겠다.
3. **액션 플랜**
  - NumPy 배열의 인덱싱, 슬라이싱, `axis` 연산을 간단한 예제로 반복해서 연습하겠다.
  - 리스트와 NumPy 배열의 연산 결과를 비교하면서 두 자료구조의 차이를 정리하겠다.
  - 직접 작은 DataFrame을 생성하고 컬럼 추가, 조건 필터링, 통계 계산, 정렬까지 한 번에 수행해보겠다.
  - 주가, 성적, 상품 판매량처럼 익숙한 데이터를 활용하여 간단한 분석 문제를 만들어 풀어보겠다.
  - 실습 과정에서 발생한 오류 메시지를 확인하고, 원인과 해결 방법을 함께 기록하겠다.
4. **함께 나누고 싶은 점**
  - 데이터 분석은 각각의 문법을 따로 외우는 것보다 데이터 생성, 필터링, 계산, 정렬의 흐름을 연결해서 이해하는 것이 중요하다고 느꼈다.
  - NumPy는 빠른 수치 계산에 적합하고, Pandas는 이름이 붙은 표 데이터를 다루는 데 적합하다는 차이가 있다.
  - Pandas가 NumPy를 기반으로 동작하기 때문에 NumPy의 기본 원리를 충분히 이해하면 Pandas를 학습하는 데 도움이 될 것 같다.
