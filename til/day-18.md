# Day 18. 멀티모달과 AI Agent

> 작성일: 2026-08-06

## 📝 오늘 배운 내용 요약
1. **Vision과 Whisper를 통해 멀티모달 AI의 기본 개념을 학습했다**
  - 멀티모달 AI는 텍스트뿐 아니라 이미지, 음성, 영상처럼 서로 다른 형태의 정보를 처리하는 AI이다.
  - BLIP 기반 이미지 캡셔닝은 이미지를 입력받아 장면을 설명하는 문장을 생성하며, ViT 기반 분류 모델은 이미지의 범주를 예측한다.
  - Whisper는 음성 파일을 텍스트로 변환하는 음성 인식 모델이며, 다국어 음성을 처리할 수 있다.
  - 모델마다 처리할 수 있는 입력 형태가 다르므로 텍스트, 이미지와 음성 입력에 맞는 Pipeline을 선택해야 한다.
2. **이미지 생성과 멀티모달 질의응답을 이해했다**
  - Diffusion 모델은 노이즈에서 시작해 반복적으로 노이즈를 제거하면서 텍스트 프롬프트에 맞는 이미지를 생성한다.
  - Stable Diffusion에서는 프롬프트로 대상, 배경과 스타일을 지정하고 Negative Prompt로 원하지 않는 특징을 제한할 수 있다.
  - VQA는 이미지와 텍스트 질문을 동시에 입력받아 이미지에 관한 구체적인 질문에 답하는 방식이다.
  - OCR 후 텍스트만 분석하는 단계적 방식과 달리 멀티모달 통합 모델은 이미지의 전체 맥락을 유지하며 처리할 수 있다.
3. **AI Agent와 Function Calling의 작동 원리를 학습했다**
  - 일반 LLM은 학습된 패턴을 바탕으로 텍스트를 생성하므로 정확한 계산이나 실시간 정보 처리에 한계가 있다.
  - AI Agent는 문제 해결에 필요한 도구를 판단하고 호출한 뒤, 도구의 실행 결과를 사용해 최종 답변을 만드는 시스템이다.
  - Function Calling에서는 모델이 필요한 함수 이름과 인자를 구조화된 형식으로 요청하고, 프로그램이 실제 함수를 실행한 결과를 다시 모델에 전달한다.
  - 계산기, 시간, 날씨와 검색 도구를 연결하면 모델을 재학습하지 않고도 기능을 확장할 수 있다.
4. **MCP를 외부 도구 연결을 위한 표준 프로토콜로 이해했다**
  - MCP는 AI 모델이 파일, 데이터베이스와 외부 도구에 연결되는 방식을 표준화한 Model Context Protocol이다.
  - 개별 Function Calling은 AI 서비스마다 연결 코드를 따로 구현해야 하지만, MCP Server는 표준을 지원하는 여러 AI에서 재사용할 수 있다.
  - MCP는 사용자가 사용하는 Host, 서버와 통신하는 Client, 실제 도구와 데이터를 제공하는 Server로 구성된다.
  - 표준화는 재사용성을 높이지만, 외부 도구에 접근하는 만큼 최소 권한, 입력 검증과 실행 전 확인 같은 안전장치가 필요하다.
## 💭 오늘의 회고
1. **배운 점**
  - 생성형 AI가 텍스트 생성에만 머무르지 않고 이미지와 음성을 이해하거나 생성하며, 외부 도구를 사용해 실제 행동까지 수행할 수 있다는 흐름을 이해했다.
  - Function Calling은 모델이 함수를 직접 실행하는 것이 아니라 호출 요청을 만들고, 프로그램이 실행을 담당하는 구조임을 배웠다.
  - MCP는 특정 도구 하나의 기능이 아니라 여러 AI와 외부 시스템 사이의 연결 방식을 통일하는 규격이라는 점을 이해했다.
2. **어려운 점/개선할 점**
  - 이미지, 음성과 텍스트 모델마다 입력 형식과 전처리 과정이 달라 적절한 Pipeline을 구분하는 것이 어려웠다.
  - Agent가 도구를 선택하는 판단 과정과 프로그램이 실제 함수를 실행하는 과정을 분리해서 이해할 필요가 있다.
  - 외부 도구의 권한이 커질수록 잘못된 호출과 Prompt Injection의 위험도 커지므로 보안 설계를 추가로 공부해야 한다.
3. **액션 플랜**
  - 이미지 캡셔닝과 VQA를 같은 이미지에 적용해 일반 설명과 구체적 질의응답의 차이를 비교한다.
  - 간단한 계산기와 현재 시각 함수를 만들고, 사용자 요청에 따라 적절한 함수를 선택하는 Agent 흐름을 구현한다.
  - MCP의 Host, Client와 Server 역할을 실제 사용 중인 AI 도구 연결 사례에 대응해 정리한다.
4. **함께 나누고 싶은 점**
  - Agent가 도구를 사용할 수 있다는 것은 편리함뿐 아니라 실제 시스템에 영향을 줄 수 있다는 의미이므로 실행 권한과 검증 절차를 함께 설계해야 한다.
