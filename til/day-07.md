# Day 7. 데이터 시각화

> 작성일: 2026-07-22

## 📝 오늘 배운 내용 요약
1. **데이터 시각화의 목적과 그래프 선택 기준을 학습했다**
  - 데이터 시각화는 숫자를 보기 좋게 꾸미는 것이 아니라 데이터의 비교, 분포, 추세, 관계와 이상치를 빠르게 파악하고 전달하는 과정이라는 점을 배웠다.
  - 범주별 크기 비교에는 막대그래프, 시간에 따른 변화에는 선그래프, 분포에는 히스토그램과 박스플롯, 두 변수의 관계에는 산점도가 적합하다는 점을 정리했다.
  - 그래프의 제목과 축 이름을 명확히 표시하고, 불필요한 장식과 과도한 색상을 줄여야 핵심 메시지가 잘 전달된다는 점을 이해했다.
2. **Matplotlib으로 기본 그래프를 작성하고 세부 요소를 설정했다**
  - `plt.plot()`, `plt.bar()`, `plt.scatter()`, `plt.hist()`, `plt.boxplot()`을 활용해 데이터의 목적에 맞는 그래프를 만들었다.
  - `title()`, `xlabel()`, `ylabel()`, `legend()`, `figsize`를 사용해 제목, 축 이름, 범례와 그래프 크기를 조정했다.
  - Matplotlib은 자유도가 높아 보고서나 인쇄물처럼 세밀한 조정이 필요한 정적 시각화에 적합하다는 점을 알게 됐다.
3. **Seaborn을 활용한 통계 시각화를 실습했다**
  - `barplot()`, `countplot()`, `histplot()`, `boxplot()`, `scatterplot()`, `heatmap()`을 활용해 범주 비교, 분포, 이상치와 상관관계를 표현했다.
  - Seaborn은 Pandas DataFrame의 컬럼명을 직접 지정할 수 있고 기본 스타일이 깔끔해 탐색적 데이터 분석에 편리했다.
  - Matplotlib이 그래프의 기반과 세부 설정을 담당하고, Seaborn은 통계 그래프를 더 간결하게 만드는 관계임을 이해했다.
4. **여러 그래프의 배치와 스타일 설정 방법을 학습했다**
  - `plt.subplot()`과 `plt.subplots()`의 차이를 비교하고, 여러 그래프를 체계적으로 관리할 때는 Figure와 Axes 배열을 반환하는 `subplots()`가 더 편리하다는 점을 배웠다.
  - 2×2 구조에서는 `axes[행, 열]`로 접근하고, `tight_layout()`으로 제목과 레이블이 겹치지 않도록 간격을 조정했다.
  - `plt.style.use()`, `sns.set_style()`, `sns.color_palette()`로 전체 그래프의 스타일과 색상을 일관되게 설정했다.
5. **Plotly를 활용해 인터랙티브 그래프를 만들었다**
  - `plotly.express`의 `px.line()`, `px.bar()`, `px.scatter()`를 사용해 선그래프, 막대그래프와 산점도를 작성했다.
  - Plotly는 hover, zoom, pan, 범례 선택 기능이 기본으로 제공되어 데이터를 직접 탐색하거나 웹 대시보드에 활용하기 좋다는 점을 배웠다.
  - 정적인 보고서에는 Matplotlib, 통계적 탐색에는 Seaborn, 사용자가 직접 조작하는 웹 시각화에는 Plotly가 적합하다는 기준을 정리했다.
## 💭 오늘의 회고
1. **배운 점**
  - 시각화에서 가장 중요한 것은 예쁜 그래프가 아니라 분석 목적에 맞는 차트를 선택하고 왜곡 없이 메시지를 전달하는 것임을 배웠다.
  - 같은 데이터도 막대, 선, 산점도 등 표현 방식에 따라 보이는 인사이트가 달라질 수 있다는 점이 인상적이었다.
2. **어려운 점/개선할 점**
  - Matplotlib과 Seaborn에서 비슷한 그래프를 만드는 함수와 인자 이름이 달라 혼동되는 부분이 있었다.
  - `subplots()`가 반환하는 Axes 배열의 차원과 접근 방법을 더 익힐 필요가 있다.
3. **액션 플랜**
  - 하나의 데이터셋으로 비교, 분포, 추세, 관계를 각각 표현하는 그래프를 만들어 차이를 복습한다.
  - 동일한 그래프를 Matplotlib, Seaborn, Plotly로 각각 작성해 코드와 결과물의 차이를 정리한다.
4. **함께 나누고 싶은 점**
  - 그래프를 그리기 전에 ‘무엇을 비교하거나 설명하려는가’를 한 문장으로 정의하면 차트 종류와 필요한 요소를 선택하기 쉬워진다.
