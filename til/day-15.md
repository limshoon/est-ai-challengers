# Day 15. 임베딩과 LLM 모델 활용

> 작성일: 2026-08-03

## 📝 오늘 배운 내용 요약
1. **임베딩으로 단어와 문장의 의미를 벡터로 표현하는 방법을 학습했다**
  - One-Hot 인코딩은 단어를 서로 독립된 값으로 표현하므로 단어 사이의 의미적 관계를 반영하기 어렵다.
  - 임베딩은 의미가 비슷한 단어나 문장을 벡터 공간에서 가깝게 배치하는 밀집 벡터 표현이다.
  - 두 벡터의 방향이 얼마나 유사한지는 코사인 유사도로 계산하며, 의미 기반 검색과 추천 시스템 등에 활용할 수 있다.
  - SentenceTransformer와 같은 사전학습 모델을 사용하면 문장을 고정 길이의 임베딩 벡터로 변환할 수 있다.
2. **Transformer와 GPT의 기본 구조를 학습했다**
  - Transformer는 Self-Attention을 통해 문장 안의 각 토큰이 다른 토큰과 어떤 관계를 갖는지 계산한다.
  - Query와 Key로 관련도 점수를 구하고 Softmax를 적용한 뒤, 그 가중치를 Value에 반영해 문맥 정보를 만든다.
  - GPT는 Transformer의 Decoder 구조를 기반으로 이전 토큰을 보고 다음 토큰을 예측하는 방식으로 문장을 생성한다.
  - 입력 문장은 Tokenizer를 거쳐 토큰 ID로 변환되며, 모델의 Context Window 범위 안에서 문맥을 처리한다.
3. **Hugging Face Pipeline으로 사전학습 모델을 활용했다**
  - Hugging Face는 공개된 사전학습 모델과 데이터셋을 공유하고 사용할 수 있는 플랫폼이다.
  - `pipeline()`은 모델과 Tokenizer를 불러오고 입력 전처리, 추론과 결과 후처리를 하나의 흐름으로 처리한다.
  - 감정 분석, 텍스트 생성, 번역, 요약과 Zero-Shot 분류 등 다양한 NLP 작업을 간단한 코드로 실행할 수 있다.
  - Pipeline은 빠른 실험과 기준 모델 구축에 유용하지만, 세부 설정이나 학습 과정을 직접 제어할 때는 모델과 Tokenizer를 별도로 다뤄야 한다.
4. **Fine-tuning과 LoRA의 차이를 이해했다**
  - Fine-tuning은 사전학습 모델을 특정 데이터와 목적에 맞게 추가 학습해 성능을 조정하는 방법이다.
  - 전체 파라미터를 학습하는 Full Fine-tuning은 높은 연산 자원과 저장 공간이 필요하다.
  - LoRA는 기존 가중치를 고정하고 작은 저차원 행렬만 학습하는 PEFT 방식으로, 학습해야 할 파라미터 수를 크게 줄인다.
  - 모델 학습 방식뿐 아니라 데이터의 품질, 라벨의 일관성과 평가 기준을 함께 관리해야 실제 성능을 높일 수 있다.
## 💭 오늘의 회고
1. **배운 점**
  - 임베딩은 텍스트를 단순히 숫자로 바꾸는 것을 넘어 의미적 관계를 벡터 공간에 표현하는 기술임을 이해했다.
  - Transformer의 Self-Attention과 GPT의 다음 토큰 예측 원리가 Hugging Face의 텍스트 생성 기능으로 연결되는 흐름을 확인했다.
  - 모든 모델을 처음부터 학습하기보다 사전학습 모델을 먼저 활용하고, 필요한 경우에만 Fine-tuning이나 LoRA를 적용하는 것이 효율적이라는 점을 배웠다.
2. **어려운 점/개선할 점**
  - Self-Attention에서 Query, Key와 Value가 실제 Tensor 연산으로 변환되는 과정을 직관적으로 이해하기 어려웠다.
  - Pipeline이 자동으로 처리하는 Tokenizer, 모델 입력과 후처리 단계를 구분해 볼 필요가 있다.
  - Full Fine-tuning과 LoRA의 자원 사용량 및 성능 차이를 실제 실습으로 비교하지 못했다.
3. **액션 플랜**
  - 의미가 비슷한 문장과 다른 문장을 각각 임베딩하고 코사인 유사도를 비교한다.
  - Hugging Face Pipeline으로 감정 분석, 요약과 텍스트 생성을 실행하고 작업별 입력·출력 형식을 정리한다.
  - LoRA 적용 전후의 학습 파라미터 수를 확인하고, 전체 Fine-tuning과의 차이를 표로 정리한다.
4. **함께 나누고 싶은 점**
  - 사전학습 모델은 빠르게 결과를 만들 수 있지만, 모델의 출력이 정확한 사실이라는 의미는 아니므로 사용 목적에 맞는 평가와 검증이 필요하다.
