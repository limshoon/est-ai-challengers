# Day 2. Python 기초 문법

> 작성일: 2026-07-14

## 📝 오늘 배운 내용 요약
1. **변수와 자료형**
  - 변수는 값을 저장하고 다시 사용하기 위해 이름을 붙인 공간이다.
  - Python에서 `=`는 두 값이 같다는 의미가 아니라 오른쪽의 값을 왼쪽 변수에 저장하는 대입 연산자이다.
  - 변수명에는 영문자, 숫자, 언더바를 사용할 수 있지만 숫자로 시작할 수 없다.
  - `if`, `for`, `class`와 같은 예약어는 변수명으로 사용할 수 없다.
  - Python에서는 일반적으로 `my_math_score`와 같은 `snake_case` 방식으로 변수명을 작성한다.
  - Python의 기본 자료형인 `int`, `float`, `str`, `bool`의 특징을 학습했다.
  	- `int`: 소수점이 없는 정수
  	- `float`: 소수점이 있는 실수
  	- `str`: 문자와 문장을 저장하는 문자열
  	- `bool`: `True`와 `False`로 표현되는 논리값
  - `type()` 함수를 사용하면 변수에 저장된 값의 자료형을 확인할 수 있다.
  - Python은 변수의 자료형을 미리 선언하지 않아도 값에 따라 자료형이 결정되는 동적 타이핑 언어이다.
  - 동적 타이핑은 코드를 빠르고 간단하게 작성할 수 있다는 장점이 있지만, 실행하기 전까지 자료형 오류를 발견하기 어려울 수 있다는 단점이 있다.
  - `int()`, `float()`, `str()`, `bool()` 함수를 이용해 자료형을 직접 변환하는 명시적 형변환을 학습했다.
  - `int`와 `float`을 함께 계산할 때 Python이 자동으로 `float`으로 변환하는 암묵적 형변환에 대해 배웠다.
  - 문자열을 숫자로 바꿀 때는 형변환 함수를 직접 사용해야 한다는 점을 알게 되었다.
  - `"3.5"`와 같은 문자열은 바로 `int()`로 바꿀 수 없으며, 먼저 `float()`으로 변환한 뒤 `int()`로 바꿔야 한다는 점을 확인했다.
2. **연산자**
  - Python에서 값을 계산하거나 비교하고 여러 조건을 조합하기 위해 사용하는 다양한 연산자를 학습했다.
  - 산술 연산자의 종류와 특징을 배웠다.
  	- `+`: 덧셈
  	- : 뺄셈
  	- : 곱셈
  	- `/`: 나눗셈
  	- `//`: 몫
  	- `%`: 나머지
  	- `*`: 거듭제곱
  - `/` 연산자는 두 정수가 정확히 나누어지더라도 결과를 항상 실수형으로 반환한다.
  - `//`와 `%`를 활용하면 전체 묶음의 개수와 남은 개수를 계산할 수 있다.
  - `%` 연산자는 숫자가 짝수인지 홀수인지 판별할 때도 활용할 수 있다.
  - `>`, `<`, `>=`, `<=`, `==`, `!=`와 같은 비교 연산자의 결과는 항상 `True` 또는 `False`로 반환된다.
  - 값을 저장하는 `=`와 값이 같은지 비교하는 `==`를 구분해야 한다는 점을 학습했다.
  - `and`, `or`, `not` 논리 연산자를 이용해 여러 조건을 하나의 조건으로 결합하는 방법을 배웠다.
  	- `and`: 모든 조건이 참일 때 참이 된다.
  	- `or`: 하나 이상의 조건이 참일 때 참이 된다.
  	- `not`: 참과 거짓을 반대로 변환한다.
  - `in`과 `not in`을 사용하면 특정 값이 리스트나 문자열 안에 포함되어 있는지 확인할 수 있다.
  - `==`는 두 값의 내용이 같은지 확인하고, `is`는 두 변수가 메모리에서 같은 객체를 가리키는지 확인한다.
  - 일반적인 값 비교에는 `is`가 아니라 `==`를 사용하는 것이 적절하다는 점을 알게 되었다.
  - `+=`, `=`, `=`, `//=`와 같은 복합 대입 연산자를 사용하면 기존 변수의 값을 간단하게 수정할 수 있다.
3. **입력과 출력**
  - `print()` 함수를 이용해 문자열, 숫자, 불리언 등 여러 자료형의 값을 화면에 출력하는 방법을 학습했다.
  - `print()` 안에서 여러 값을 쉼표로 구분하면 각 값 사이에 자동으로 공백이 들어간다.
  - `sep` 옵션을 사용하면 출력되는 값 사이의 구분자를 변경할 수 있다.
  - `end` 옵션을 사용하면 출력이 끝난 뒤 줄바꿈 대신 다른 문자를 출력할 수 있다.
  - `input()` 함수를 사용해 사용자가 입력한 값을 변수에 저장하는 방법을 배웠다.
  - 사용자가 숫자를 입력하더라도 `input()`으로 받은 값은 항상 문자열 자료형으로 저장된다.
  - 입력받은 값을 계산에 사용하려면 `int(input())` 또는 `float(input())`와 같이 형변환해야 한다.
  - 문자열 상태의 숫자를 형변환하지 않고 더하면 실제 덧셈이 아니라 문자열 연결이 이루어진다.
  - 여러 값을 각각 입력받는 방법과 한 줄에 여러 값을 입력한 뒤 `split()`으로 나누는 방법이 있다.
  - 서로 다른 의미를 가진 값을 입력받을 때는 여러 번 `input()`을 사용하는 것이 적절하다.
  - 같은 종류의 값을 한 번에 입력받을 때는 `split()`을 활용하는 것이 효율적이라는 점을 배웠다.
4. **조건문**
  - 조건문은 특정 조건의 참과 거짓에 따라 프로그램이 서로 다른 동작을 수행하도록 만드는 문법이다.
  - `if`는 첫 번째 조건을 검사한다.
  - `elif`는 앞선 조건이 거짓일 때 새로운 조건을 검사한다.
  - `else`는 모든 조건이 거짓일 때 실행된다.
  - 조건식 뒤에는 반드시 콜론을 작성해야 한다.
  - 조건에 포함되는 코드는 일정한 수준으로 들여쓰기해야 한다.
  - Python은 중괄호가 아니라 들여쓰기로 코드 블록을 구분한다.
  - 따라서 들여쓰기는 단순한 가독성의 문제가 아니라 문법적으로 중요한 요소이다.
  - `if`문은 단독으로 사용할 수 있으며 조건이 거짓일 때 실행할 코드가 없다면 `else`를 생략할 수 있다.
  - 독립된 여러 개의 `if`문은 각각의 조건을 모두 검사한다.
  - 여러 조건을 동시에 만족하면 여러 개의 코드가 모두 실행될 수 있다.
  - 반면 `if-elif-else`문은 위에서부터 조건을 검사하고 가장 먼저 참이 된 조건의 코드 하나만 실행한다.
  - 여러 조건 중 하나를 선택해야 할 때는 `if-elif-else`를 사용해야 한다.
  - 각각의 조건을 독립적으로 확인해야 할 때는 여러 개의 `if`문을 사용해야 한다.
  - 중첩 조건문을 이용하면 하나의 조건이 참일 때 내부에서 추가 조건을 검사할 수 있다.
  - 단순한 조건은 `참일 때 값 if 조건 else 거짓일 때 값` 형태의 조건부 표현식으로 한 줄에 작성할 수 있다.
  - 조건문이 복잡해지거나 중첩 깊이가 깊어지면 가독성이 떨어질 수 있다.
  - 따라서 가능한 한 조건문을 단순하게 구성하는 것이 중요하다.
5. **반복문**
  - 반복문은 같은 작업을 여러 번 수행할 때 사용하는 문법이다.
  - 반복할 대상이나 횟수가 정해져 있을 때는 `for`문을 사용한다.
  - 특정 조건이 참인 동안 반복해야 할 때는 `while`문을 사용한다.
  - `range()` 함수를 사용하면 일정한 범위의 숫자를 생성하여 반복할 수 있다.
  - `range(시작, 끝, 증가폭)`에서 끝에 작성한 숫자는 실제 반복 범위에 포함되지 않는다.
  - 반복문 안에서 변수의 값을 계속 더하는 누적 방식을 이용하면 합계를 구할 수 있다.
  - `while`문에서 반복 조건을 변화시키지 않으면 무한 반복이 발생할 수 있다.
  - 따라서 `while`문을 사용할 때는 종료 조건을 반드시 작성해야 한다.
  - `break`는 조건을 만족했을 때 반복문 전체를 즉시 종료한다.
  - `continue`는 반복문을 종료하지 않고 현재 순서의 실행만 건너뛴 뒤 다음 반복을 계속 진행한다.
  - 중첩 반복문에서 `break`를 사용하면 모든 반복문이 종료되는 것이 아니라 자신이 포함된 가장 가까운 반복문만 종료된다.
  - `enumerate()`를 활용하면 리스트의 값뿐만 아니라 각 값의 순서와 인덱스를 함께 사용할 수 있다.

## 💭 오늘의 회고
1. **배운 점**
  - 오늘 수업을 통해 Python 프로그램은 데이터를 변수에 저장하고, 연산자를 이용해 값을 계산하며, 조건문으로 상황을 판단하고, 반복문으로 작업을 반복하는 흐름으로 구성되어 있다는 점을 배웠다.
  - 각각의 문법은 독립적인 기능처럼 보이지만 실제 프로그램에서는 서로 연결되어 사용된다는 점을 알게 되었다.
  - 예를 들어 `input()`으로 값을 입력받고, 자료형을 숫자로 변환한 뒤, 조건문으로 값을 판별하고, 반복문으로 여러 번 실행할 수 있다.
  - Python은 다른 언어에 비해 문법이 비교적 간단하지만, 자료형과 들여쓰기와 같은 기본적인 규칙을 정확히 지키지 않으면 오류가 발생할 수 있다는 점을 배웠다.
  - 코드를 단순히 암기하기보다는 각각의 문법이 어떤 상황에서 필요한지 이해하는 것이 중요하다고 느꼈다.
  - 특히 `input()`의 결과가 항상 문자열이라는 점과 자료형이 다른 값끼리 계산할 때 형변환이 필요하다는 점이 중요했다.
  - 변수, 조건문, 반복문이 서로 연결되어 하나의 프로그램 흐름을 구성한다는 점을 이해했다.
2. **어려운 점/개선할 점**
  - 반복문의 시작 조건과 종료 조건을 먼저 설계하는 연습이 필요하다.
  - 아직은 예제 코드를 참고하지 않고 처음부터 직접 코드를 작성하는 데 어려움이 있었다.
  - 짧고 간단한 문제부터 반복적으로 풀면서 문법을 익힐 필요가 있다.
3. **액션 플랜**
  - `break`와 `continue`가 포함된 반복문을 직접 실행해볼 예정이다.
  - 반복할 때마다 변수의 값을 출력해 코드가 진행되는 순서를 확인할 예정이다.
  - `while`문을 이용해 사용자가 `"그만"`을 입력할 때까지 입력을 반복해서 받는 프로그램을 작성할 예정이다.
