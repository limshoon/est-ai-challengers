# Day 12. 모델 성능 향상과 신경망 기초

> 작성일: 2026-07-29

## 📝 오늘 배운 내용 요약
1. **교차검증과 GridSearchCV를 활용한 모델 선택 방법을 학습했다**
  - 교차검증은 데이터를 여러 폴드로 나누어 학습과 검증을 반복함으로써 한 번의 분할에 따른 성능 변동을 줄이는 방법이다.
  - `GridSearchCV`에 모델, 탐색할 하이퍼파라미터, 교차검증 폴드 수와 평가 지표를 전달해 최적 조합을 찾았다.
  - `best_params_`로 최적 하이퍼파라미터를 확인하고, 최종 테스트 데이터는 탐색에 사용하지 않고 마지막 평가에만 사용해야 한다.
2. **과소적합·과대적합을 진단하고 하이퍼파라미터를 조정했다**
  - 트리의 `max_depth`, 앙상블의 `n_estimators`, 로지스틱 회귀의 `C`처럼 모델의 복잡도를 결정하는 값을 하이퍼파라미터라고 한다.
  - Validation Curve는 하나의 하이퍼파라미터 변화에 따른 훈련·검증 성능을 보여 주고, Learning Curve는 데이터 양에 따른 성능 변화를 보여 준다.
  - 두 곡선을 활용하면 모델 복잡도를 조절해야 하는지, 데이터를 더 모아야 하는지 판단할 수 있다는 점을 배웠다.
3. **SHAP을 활용해 모델의 예측 근거를 설명했다**
  - SHAP은 게임이론의 Shapley Value를 기반으로 각 특성이 예측값에 기여한 정도를 계산한다.
  - `TreeExplainer`로 트리 기반 모델의 SHAP 값을 계산하고, `summary_plot()`으로 전체 특성의 영향 방향과 크기를 확인했다.
  - 개별 예측은 force plot 등으로 설명할 수 있어 단순 Feature Importance보다 특정 사례의 예측 근거를 자세히 확인할 수 있다.
4. **Pipeline과 ColumnTransformer로 전처리와 모델을 연결했다**
  - `Pipeline`은 스케일링, 인코딩과 모델 학습 단계를 하나의 객체로 묶어 처리 순서와 일관성을 관리한다.
  - `ColumnTransformer`는 수치형 컬럼에는 스케일링, 범주형 컬럼에는 인코딩처럼 컬럼 종류별로 서로 다른 전처리를 적용한다.
  - 파이프라인 안의 하이퍼파라미터는 `단계이름__파라미터` 형식으로 `GridSearchCV`에서 탐색할 수 있다.
  - Pipeline을 사용하면 데이터 누수를 줄이고 학습과 예측 시 동일한 전처리를 보장하며 배포와 재현도 쉬워진다.
5. **퍼셉트론과 다층 신경망의 구조를 학습했다**
  - 퍼셉트론은 입력값의 가중합에 편향을 더하고 활성화 함수를 적용하는 가장 단순한 인공 뉴런이다.
  - 단일 퍼셉트론은 선형적으로 분리 가능한 문제만 해결할 수 있어 XOR과 같은 비선형 문제를 풀 수 없다.
  - 입력층, 하나 이상의 은닉층, 출력층으로 구성된 다층 퍼셉트론은 은닉층을 통해 복잡한 비선형 패턴을 학습한다.
6. **활성화 함수의 역할과 종류를 비교했다**
  - 활성화 함수가 없으면 여러 층을 쌓아도 전체 모델이 하나의 선형식과 같아져 복잡한 패턴을 학습할 수 없다.
  - Sigmoid는 0\~1 범위로 변환해 이진 분류 출력층에 적합하지만 깊은 신경망에서는 기울기 소실 문제가 있다.
  - ReLU는 계산이 빠르고 기울기 소실을 줄여 은닉층에 널리 사용되며, Tanh는 -1\~1 범위를 갖는다.
  - Softmax는 다중 클래스 출력층에서 각 클래스 값을 합이 1인 확률 분포로 변환한다.
## 💭 오늘의 회고
1. **배운 점**
  - 모델 성능을 높이기 위해서는 하이퍼파라미터 탐색뿐 아니라 안전한 전처리 흐름, 교차검증과 설명 가능성을 함께 고려해야 한다.
  - Pipeline은 코드 편의 기능을 넘어 데이터 누수와 전처리 불일치를 방지하는 중요한 도구임을 배웠다.
  - 신경망도 입력, 가중치, 편향, 활성화 함수의 조합으로 구성되며 기존 머신러닝 개념과 연결된다는 점을 이해했다.
2. **어려운 점/개선할 점**
  - 교차검증과 GridSearchCV의 실행 흐름, Pipeline 내부 파라미터 이름 지정 방식이 익숙하지 않았다.
  - SHAP 그래프의 색상과 값이 예측을 높이거나 낮추는 방향을 정확히 해석하는 연습이 필요하다.
  - 활성화 함수마다 적합한 층과 장단점을 구분해 기억할 필요가 있다.
3. **액션 플랜**
  - 수치형과 범주형 컬럼이 섞인 데이터셋으로 ColumnTransformer와 Pipeline을 직접 구성한다.
  - Pipeline을 GridSearchCV와 연결해 최적 파라미터를 찾고 테스트 성능과 SHAP 설명을 함께 정리한다.
  - XOR 예제로 단일 퍼셉트론의 한계와 다층 신경망의 차이를 시각적으로 확인한다.
4. **함께 나누고 싶은 점**
  - 좋은 모델은 점수가 높은 모델만이 아니라 평가 과정이 공정하고, 전처리가 재현 가능하며, 예측 근거를 설명할 수 있는 모델이라고 생각한다.
