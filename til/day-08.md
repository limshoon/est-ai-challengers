# Day 8. 데이터 전처리와 데이터 병합

> 작성일: 2026-07-23

## 📝 오늘 배운 내용 요약
1. **Plotly 대시보드와 데이터 전처리의 전체 흐름을 학습했다**
  - `make_subplots()`로 여러 그래프를 하나의 화면에 배치하고 `add_trace()`와 `update_layout()`으로 차트와 전체 레이아웃을 구성했다.
  - 대시보드는 여러 지표를 한 화면에서 종합적으로 비교하는 데 유용하며, 필요하면 드롭다운 같은 인터랙션을 추가할 수 있다는 점을 배웠다.
  - 원시 데이터를 분석이나 머신러닝에 적합하도록 정리하는 전처리 과정이 데이터 품질과 모델 성능을 결정한다는 점을 이해했다.
2. **결측치를 확인하고 상황에 맞게 처리했다**
  - `isna().sum()`과 `isna().mean()`으로 컬럼별 결측치 개수와 비율을 확인했다.
  - 수치형 데이터는 평균이나 중앙값, 범주형 데이터는 최빈값으로 대체하는 방법을 실습했다.
  - 결측치를 무조건 삭제하기보다 발생 원인, 비율, 컬럼의 의미와 분석 목적을 확인한 뒤 삭제 또는 대체 방법을 선택해야 한다는 점을 배웠다.
3. **이상치를 탐지하고 처리하는 방법을 학습했다**
  - `describe()`와 박스플롯으로 데이터 범위와 비정상적인 값을 1차로 확인했다.
  - IQR 방식에서 `Q1 - 1.5×IQR`보다 작거나 `Q3 + 1.5×IQR`보다 큰 값을 이상치 후보로 판단했다.
  - Z-score는 평균에서 표준편차 몇 배만큼 떨어져 있는지 측정하며, 정규분포에 가까운 데이터에서 활용하기 적합하다는 점을 이해했다.
  - 이상치는 오류일 수도 있지만 실제 중요한 사례일 수도 있으므로 제거, 경계값 대체(`clip()`), 변환 여부를 맥락에 따라 결정해야 한다.
4. **자료형 변환과 중복 데이터 처리를 실습했다**
  - `astype()`으로 자료형을 명시적으로 변환하고, `pd.to_numeric(errors="coerce")`로 변환 실패 값을 결측치로 처리했다.
  - `pd.to_datetime()`과 `.dt` 접근자를 사용해 문자열 날짜를 변환하고 연, 월, 일 정보를 추출했다.
  - `replace()`와 `map()`의 차이를 비교하고, `duplicated()`와 `drop_duplicates()`로 중복 데이터를 확인하고 제거했다.
5. **여러 데이터셋을 병합하고 구조를 재구성했다**
  - `pd.concat()`은 같은 구조의 데이터를 행 또는 열 방향으로 이어 붙일 때 사용했다.
  - `pd.merge()`는 특정 키를 기준으로 데이터를 결합하며 `inner`, `left`, `right`, `outer` 방식의 차이를 학습했다.
  - `join()`은 인덱스를 기준으로 병합하고, `pivot_table()`은 행과 열의 기준을 정해 집계 결과를 재구성할 때 활용했다.
  - `pd.json_normalize()`를 사용해 중첩된 JSON 데이터를 표 형태로 변환하는 방법을 익혔다.
6. **`apply()`****를 활용해 복잡한 데이터 변환을 수행했다**
  - `Series.apply()`로 각 값에 함수를 적용하고, `DataFrame.apply(axis=0)`은 컬럼 단위, `axis=1`은 행 단위로 함수를 적용한다는 점을 배웠다.
  - 여러 값을 `pd.Series`로 반환하면 한 번에 여러 파생 컬럼을 만들 수 있었다.
  - 단순 계산은 벡터 연산이 더 빠르므로 `apply()`는 벡터화하기 어려운 복잡한 규칙에 사용하는 것이 좋다는 점을 이해했다.
## 💭 오늘의 회고
1. **배운 점**
  - 데이터 전처리는 단순히 비어 있는 값을 채우는 작업이 아니라 데이터의 의미와 품질을 확인하고 분석 가능한 형태로 만드는 과정임을 배웠다.
  - 병합 방식에 따라 결과 행 수와 결측치가 달라지므로 병합 전후의 크기와 키 중복 여부를 반드시 확인해야 한다.
2. **어려운 점/개선할 점**
  - 결측치와 이상치를 제거할지 대체할지 판단하는 기준은 데이터의 맥락에 따라 달라 어려웠다.
  - `merge()`의 결합 방식과 `apply()`의 `axis` 방향을 반복해서 연습할 필요가 있다.
3. **액션 플랜**
  - 결측치, 중복값, 이상치가 포함된 작은 데이터셋을 만들고 진단부터 처리까지 전처리 과정을 직접 수행한다.
  - `inner`, `left`, `outer` 병합 결과의 행 수와 결측치를 표로 비교한다.
4. **함께 나누고 싶은 점**
  - 전처리 전후의 데이터 크기와 변경 이유를 기록하면 분석 결과를 재현하고 설명하기 쉬워진다.
