# Day 1. 개발환경 구축 및 AI 기초

> 작성일: 2026-07-13

## 📝 오늘 배운 내용 요약
1. 개발환경과 Google Colab
  - 개발환경은 코드를 작성하고 실행하며 결과를 확인하는 작업 공간이다.
  - Google Colab은 별도의 설치 없이 Python을 실행할 수 있는 클라우드 기반 개발환경이다.
  - 코드 셀과 마크다운 셀의 차이, 셀 실행 및 기본 단축키를 익혔다.
2. Python과 AI 기초
  - Python은 문법이 간결하고 가독성이 높아 AI와 데이터 분석에 많이 활용된다.
  - AI는 가장 넓은 개념이며, 머신러닝은 데이터를 통해 규칙을 학습하는 방법이고, 딥러닝은 인공신경망을 사용하는 머신러닝의 한 분야이다.
  - 머신러닝은 지도학습, 비지도학습, 강화학습으로 구분된다.
  - AI 프로젝트는 문제 정의, 데이터 수집·정제, 데이터 분석, 모델 학습, 평가, 활용 순서로 진행된다.
## 💭 오늘의 회고
1. **배운 점**
  - AI 모델 자체보다 문제 정의와 데이터 준비가 중요하다는 점을 배웠다.
  - Colab을 이용하면 코드와 설명을 함께 정리하며 학습할 수 있다는 점이 유용했다.
2. **어려운 점/개선할 점**
  - 머신러닝과 딥러닝의 세부 알고리즘은 아직 익숙하지 않다.
  - 수업 내용을 단순히 읽는 것보다 직접 코드를 반복해서 작성할 필요가 있다.
3. **액션 플랜**
  - 오늘 배운 내용을 다시 복습한다.
  - Colab에서 Hello, World와 import this 코드를 다시 실행한다.
  - Python 기본 문법과 Git/GitHub 기초를 예습한다.
4. **함께 나누고 싶은 점**
  - Colab에서는 Alt + Enter를 사용하면 현재 셀을 실행하고 아래에 새 셀을 추가할 수 있다.
  - 코드에 오류가 발생하면 오류 메시지의 마지막 줄부터 확인하는 습관이 중요하다.
