# Day 10. 머신러닝 기초와 회귀 모델

> 작성일: 2026-07-27

## 📝 오늘 배운 내용 요약
1. **머신러닝 평가를 위한 데이터 분할 방법을 학습했다**
  - 모델은 학습에 사용하지 않은 데이터로 평가해야 일반화 성능을 확인할 수 있다는 점을 배웠다.
  - `train_test_split()`의 `test_size`, `random_state` 옵션을 사용해 훈련 데이터와 테스트 데이터를 나눴다.
  - 분류 문제에서는 `stratify=y`로 클래스 비율을 유지하고, 시계열 데이터는 미래 정보가 과거에 섞이지 않도록 시간 순서를 보존해야 한다.
  - 더 엄격한 평가가 필요할 때는 훈련·검증·테스트의 3개 집합으로 분할할 수 있다는 점을 이해했다.
2. **Bias-Variance Tradeoff와 과소적합·과대적합을 이해했다**
  - 편향이 큰 모델은 너무 단순해 훈련 데이터의 패턴도 충분히 학습하지 못하는 과소적합 상태가 될 수 있다.
  - 분산이 큰 모델은 훈련 데이터에 지나치게 맞춰져 새로운 데이터 성능이 떨어지는 과대적합 상태가 될 수 있다.
  - 훈련 성능과 테스트 성능을 함께 비교하고 모델 복잡도를 조절해 두 오차 사이의 균형점을 찾는 것이 중요하다는 점을 배웠다.
3. **불균형 데이터의 문제와 대응 방법을 학습했다**
  - 클래스 비율이 크게 치우친 데이터에서는 다수 클래스만 예측해도 정확도가 높게 나올 수 있어 Accuracy만으로 평가하면 위험하다.
  - 소수 클래스를 늘리는 오버샘플링, 다수 클래스를 줄이는 언더샘플링, 모델에 가중치를 주는 `class_weight="balanced"` 방법을 비교했다.
  - 샘플링은 테스트 데이터에 영향을 주지 않도록 데이터 분할 후 훈련 데이터에만 적용해야 한다.
4. **여러 회귀 모델의 특징과 사용 방법을 학습했다**
  - `LinearRegression`은 변수 간 선형 관계를 가정하고 계수를 통해 결과를 해석하기 쉽다.
  - `DecisionTreeRegressor`는 조건 분기로 비선형 관계를 학습하지만 단일 트리는 과대적합 위험이 있다.
  - `RandomForestRegressor`는 여러 트리의 평균으로 분산을 줄이고, `GradientBoostingRegressor`와 `XGBRegressor`는 이전 모델의 오차를 순차적으로 보완한다.
  - 모든 모델은 `fit(X_train, y_train)`으로 학습하고 `predict(X_test)`로 예측하는 공통 흐름을 가진다.
5. **회귀 모델 평가 지표를 비교했다**
  - MAE는 절대 오차의 평균으로 원래 단위에서 해석하기 쉽고 큰 오차에 비교적 덜 민감하다.
  - MSE는 오차를 제곱해 큰 실수에 더 큰 벌점을 주고, RMSE는 MSE에 제곱근을 적용해 원래 단위로 해석할 수 있다.
  - R²는 모델이 평균 예측보다 얼마나 설명력을 갖는지 나타내며 1에 가까울수록 좋지만 음수가 나올 수도 있다.
  - 하나의 지표만 보지 않고 문제의 목적과 이상치 민감도를 고려해 여러 지표를 함께 비교해야 한다.
## 💭 오늘의 회고
1. **배운 점**
  - 모델 선택만큼 데이터 분할과 평가 설계가 중요하며, 잘못된 평가 방식은 실제 성능을 과대평가할 수 있다는 점을 배웠다.
  - 회귀 모델마다 해석력, 비선형 관계 처리와 과대적합 위험이 달라 데이터의 특성에 맞게 선택해야 한다.
2. **어려운 점/개선할 점**
  - MAE, MSE, RMSE와 R²의 값이 의미하는 바를 실제 예측 오차와 연결해 해석하는 부분이 어려웠다.
  - 편향과 분산을 개념으로는 이해했지만 모델의 하이퍼파라미터와 연결하는 연습이 필요하다.
3. **액션 플랜**
  - 동일한 회귀 데이터셋에 선형회귀, 의사결정나무와 랜덤포레스트를 적용하고 네 가지 평가 지표를 한 표로 비교한다.
  - 트리의 깊이를 바꿔 훈련 점수와 테스트 점수 변화를 확인하며 과소적합과 과대적합을 관찰한다.
4. **함께 나누고 싶은 점**
  - 테스트 데이터는 최종 성능을 확인하는 용도로 남겨 두고, 모델 선택 과정에서 반복적으로 사용하지 않는 것이 중요하다.
